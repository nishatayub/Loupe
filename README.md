# Loupe

A home for short films — upload yours, or discover what creators around the world are making.

Built with Next.js, GSAP, and Lenis.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Stack

- Next.js (App Router, Turbopack)
- Tailwind CSS v4
- GSAP + ScrollTrigger for scroll-driven animation
- Lenis for smooth scrolling
